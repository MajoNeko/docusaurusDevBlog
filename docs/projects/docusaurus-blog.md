## Quickstart
1. Create a new repository from the Developr Akademie Docusaurus template
    - Go to "https://github.com/spmse/dev-blog-template"
    - In the top left, Click on the green button "Use this template" then "Create a new repository"
    - Gives the repository a unique name and fill out a description, for example "This is my first Docusaurus developer Blog project!"
    - Your new repository should now be ready to be worked on 

2. Setup Github pages to build and deploy through Github Actions
    - On the top actions bar in your repository, click on "settings"
    - Under "Code, planning and automation", click on "Pages"
    - Under "Build and deployment" select "Github Actions" from the drop down

3. Create a project page to display the steps taken and information learned to create this blog project
    - Add a new page to the projects folder
    - Fill out the document in README.md style describing the steps taken
    - Modify as needed

4. Alter the docusaurus.config.ts file to be personalised
    - Change the title and tagline to something personal
    - Change any URLs to point to personalised URLs such as you personal github repository
    - Change the footer information to contain only relevant links to the current proejct on this blog and any URL informationto personal links

5. Don't forget to create and fill out the README.md with relevant information regarding the proejct!

6. Deploy and test the project
