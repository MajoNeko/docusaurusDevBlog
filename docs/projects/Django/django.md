# Django project

This section will cover a basic installation and project setup with Django.
Django is a python full stack web frameworkthe is free and open source. It is one of the most popular frameworks at the time of this writing and easy to use.

## Table Of Contents



## Quickstart

1. - If you haven't already, install python. You can check out the python sction of this blog for instructions on how to proceed.

2. Create a project space and setup a virtual environment (venv) by typing the following command in the terminal: python -m venv nameOfYourVirtualEnvironment

3. - When you have your venv created, you need to activate it to start working in it: .\nameOfYourVirtualEnvironment\Scripts\activate

4. - Install Django in you venv: pip install django or python -m pip install django


## Creating a Django Project

1. To create a django project you can use the following command: django-admin startproject name_of_your_django_app

2. a folder will be created with autogenerated files for your project. One import file is the manage.py which allows you to interact with the django project. You can run a local development server by using the following command: python manage.py runserver [addrport]
You can check out the official django documentation for more useful commands: https://docs.djangoproject.com/en/6.1/ref/django-admin/

3. To create an app directory with a default structure (models, views, tests, etc) use the following command: python manage.py  startapp appName.

4. The first time you run the server a new sqlite3 db will be created and you will get a migration warning, you can run python manage.py migrate to sync the db changes to your models and do this whenever you have a change between you db and your models.

5. Django creates an admin panel that can be accessed by adding admin in the url. To access this admin panel you need to create a super user in your db.
Type the following command: python manage.py createsuperuser
You will be prompted for a suer name, email and passowrd. Once you have completed those steps, you can log in to the admin panel

6. In the admin panel you can manage users, permissions, groups, and other info. You can add more components by altering the admin.py file in your project folder.
